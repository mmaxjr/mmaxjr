### Project Spotlight: SAMA - https://ceosecotec.com.br/

**SAMA** is a machine vision project focused on early detection of smoke and fire in rural environments.

The goal is to turn camera streams and image data into actionable alerts for farms, helping reduce response time in environmental risk scenarios. The project connects my experience in infrastructure, monitoring, automation, and AI into a single production-oriented system.

What I am working on:

- Smoke and fire detection using computer vision models.
- Alerting workflows for operational teams.
- Edge-friendly inference and practical deployment.
- Documentation for field usage and future contributors.

Status: private production project.
